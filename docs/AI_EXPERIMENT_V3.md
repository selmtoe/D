# CPU方策 v3 — 自己対局学習結果

## 結論

CPUは、ルールエンジンが列挙した候補をNNと公開情報だけの戦術評価で順位付けする。学習は120局の自己対局から得た10,676判断を使い、最終順位が良い対局の判断を強く、下位・失格・未完走対局の判断を弱く重み付けした。合法性の最終判断は引き続き`@daifugo/rules`と`SparkAuthority`が所有する。

v2はQA用botの24局を模倣しただけで、候補順への依存とブラインド自滅が大きかった。v3は候補生成を本番CPUと共通化し、探索を混ぜた自己対局、順位重み付き学習、ブラインド成功確率による安全フィルターを追加した。

## ブラインド方策

- 自分のブラインド札の表面はNNにも戦術評価にも渡さない。
- 場が空、初手ではない、単独出し、かつ禁止上がりにならない局面は確実に合法として早めに処理する。
- 場に札があるときは、公開済みカードから残り札を数え、枚数・縛り・革命／Jバック・スペード3返し・禁止上がりを含めて成功確率を計算する。
- パスや表向き合法手がある場合、成功確率100%未満のブラインド候補はNNへ渡さない。
- 7渡し・10捨てでは、表面を見ずにブラインド札を処理できる候補を高く評価する。
- カードIDから表面を推測しない。配札時点でIDと表面の対応は毎局ランダム化されている。

予備24局では旧教師がブラインド試行50回中42回失格だったのに対し、新方策は68回中1回だった。本学習用120局では373回中2回（0.54%）で、authority拒否と状態不変条件違反はいずれも0だった。

## 未使用seedでのv2比較

同じtest splitをv2とv3で評価した。これは勝率そのものではなく、自己対局で上位だった方策判断への一致率である。

| 指標                    |     v2 |     v3 |
| ----------------------- | -----: | -----: |
| 全判断 accuracy         | 63.77% | 77.37% |
| 順位重み付き accuracy   | 61.14% | 76.37% |
| 多候補局面 accuracy     | 30.77% | 56.76% |
| ブラインド局面 accuracy | 66.31% | 78.02% |

加えて、未使用のブラインド5枚・4人対局12局をブラウザと同じ推論経路で回し、少なくとも10局の完走、失格2人以下、全遷移のrules invariant成立を自動試験している。

## 方策の境界

これは完全情報MCTSではない。大富豪は不完全情報・多人数・特殊効果ありのため、全候補を深くrolloutするとブラウザCPUには重すぎる。v3はオフラインでは自己対局の終局順位を学び、オンラインでは小型NNと軽量戦術評価だけを使う構成にした。応答を止めず、公平な情報境界を守りながら強化しやすい折衷である。

次の段階では、同じ局面から複数候補を分岐させるcounterfactual rollout、モデル世代別リーグ、勝率の信頼区間を追加する。現在のチェックポイントはその土台として再現可能に保存している。
